## 前版更新

案例 02 / You 沿用案例 01 的六段敘事骨架與視覺系統：

1. 問題：感受與模式混合、能力證據分散、職涯方向停留在想像。
2. 判斷：區分真實經驗、反應與觀察、模式、假設、實驗與決定。
3. 設計取捨：比較直接取得 AI 結論與保留證據、假設、行動的流程。
4. 設計流程：COLLECT → OBSERVE → CONNECT → HYPOTHESIZE → EXPERIMENT → REFLECT，將決定與洞察接回新經驗。
5. 規則與介面：資料分類、四面向工作模型、假設與證據比較、低成本實驗、可更新的決定紀錄。
6. 原型學習：區分自己的真實資料操作觀察與尚待執行的外部使用者測試。

新增八張可展開的原型截圖，保留原操作影片、方案比較頁籤與章節跳轉。圖表使用網站的米白、淡綠、深綠及紅色樣式。原型中的百分比未被當作經驗證的職涯適合機率。

「把混亂的問題理解清楚，建立一套自洽、可以被使用的邏輯。」已放入 HOW I THINK 大標。首頁 You 卡片摘要同步更新，其餘五案詳情保持不變。
