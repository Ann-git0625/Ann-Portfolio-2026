# Ann — Product Designer Portfolio

以 Product Designer 為求職方向的作品集版本。

## 開啟方式

解壓縮後，以瀏覽器開啟 `index.html`。請保持 `styles.css`、`app.js` 與 `assets` 的相對位置。
如需更新既有網站，將這些檔案放入網站根目錄；本次未更新線上網站。

## 首頁板塊順序

01 / ANN / PRODUCT DESIGNER → 02 / THE SHIFT → 03 / SELECTED WORK → 04 / EXPLORATIONS → 05 / HOW I THINK → 06 / VISUAL & PRODUCTION BACKGROUND → 07 / ABOUT ANN

THE SHIFT 採章節編號、英文大標、中文敘述三欄構圖，搭配 VISUAL PRODUCTION → WORKFLOW & SYSTEMS → PRODUCT DESIGN 三階段流程；手機版改為直向排列。SELECTED WORK 與 EXPLORATIONS 各自為獨立板塊。

## 定位與順序

首頁主張：理解問題，設計下一步。

| 順序 | 案例 | 主要設計能力 | 證據類型 |
| --- | --- | --- | --- |
| 01 | Project & Risk Management | 跨角色流程、欄位與條件規則、查詢視圖 | 實務工具 |
| 02 | You | 問題定義、資訊架構、決策流程 | 自主原型 |
| 03 | Luma | 情境流程、回饋與重試、AI 互動探索 | 自主原型 |
| 04 | Knowledge Graph | 節點關係、狀態與導航 | 自主原型 |
| 05 | Knowledge Architecture | 任務導向資訊架構、知識查找 | 實務架構 |
| 06 | Learning Path | 任務分析、資訊順序、完成標準 | 實務文件 |

前三案優先展示；後三案補充資訊架構與流程能力。過往 UE 作品保留為視覺與製作背景。

六案均標示使用者、我的工作、交付內容、目前狀態與待執行的驗證方案。未將概念原型描述為商業上線產品，也未新增訪談、測試結果或量化成效。首頁原型截圖取自原附件中的操作影片。
