05 / HOW I THINK

FRAME THE PROBLEM. MAKE THE FLOW CLEAR. TEST THE ASSUMPTION.

先釐清要解決什麼，
再決定要做什麼。

  1. 01
    Understand / 理解情境

    確認誰在什麼情境下，想完成哪一件事；從現場問題與既有資料找線索。

  2. 02
    Define / 定義問題

    區分觀察與假設，釐清任務卡點、使用限制，以及設計希望改變的行為。

  3. 03
    Structure / 設計流程

    安排資訊層級、操作順序與狀態，讓使用者知道目前位置與下一步。

  4. 04
    Prototype / 具體化方案

    比較替代方案，把選擇落到文件、工具或介面原型，說清楚取捨。

  5. 05
    Validate / 驗證與調整

    以任務完成、理解程度與操作卡點檢驗假設；各案例分別標示驗證進度。
